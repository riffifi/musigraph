# Changes

Versions follow `major.minor.patch` and use matching `v` prefixed git tags. The application version lives in `Cargo.toml`; project files have a separate `MGP` format version. New releases keep readers for older project files.

## 0.2.0 — 2026-09-29

- Show embedded JPEG/PNG cover art or a matching cover image in the track folder when hovering over a queue track.
- Keep cover art in saved projects; MGP3 still opens MGP1 and MGP2 files.
- Add an About screen with the current version, author, libraries, and project format.

## 0.1.0

- Initial native audio editor with analysis, queue, transitions, themes, and project files.
